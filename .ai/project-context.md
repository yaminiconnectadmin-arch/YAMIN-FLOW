# Project Context (.ai/project-context.md)

## Project Objective
**YAMINI FLOW** is a premium Distribution Intelligence Platform (ERP) designed to connect Admins, Dealers, MNP Field Personnel, and Suppliers into a unified, secure ecosystem. The platform automates tracking, inventory ledgers, PO generation, and reconciles transactions with Tally ERP.

## Core Features
1. **RBAC Portals**: Login and dashboard screens customized to Admin, MNP, Dealer, and Supplier roles.
2. **Inventory Management**: Multicentre warehouses, real-time safety stock counts, and ledgers.
3. **Automated Procurement Engine**: Dynamic PO generator triggered by warehouse stock deficits.
4. **Tally Synchronization**: Auto and manual voucher matching, webhook tracking, and reconciliation.
5. **AI Insights Generator**: Real-time Claude Sonnet executive briefs.
