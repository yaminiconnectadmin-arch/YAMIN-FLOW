# Master AI Engineering Development Rules (.ai-rules.md)

Every AI coding assistant, agentic workflow, or engineer operating in **Yamini Flow** MUST obey these 10 commandments:

1. **Never code before understanding architecture**: Always consult `/docs/ARCHITECTURE.md` and `.ai/architecture-memory.md` before writing code.
2. **Never introduce security risks**: Never hardcode API keys, JWT secrets, or credentials. All inputs must be sanitized via Pydantic.
3. **Always validate user input**: Validate body, query, and path parameters on server boundaries.
4. **Always create tests**: Every new feature or bug fix must be accompanied by unit (`pytest`) or end-to-end (`Playwright`) tests.
5. **Always document decisions**: Update `.ai/decisions.md` and `/docs/` whenever architectural or schema modifications occur.
6. **Prefer reusable components**: Utilize existing UI components (`frontend/src/`) and shared backend utilities (`backend/`).
7. **Optimize performance**: Monitor query performance, index MongoDB collections, and enforce Lighthouse CI score > 90.
8. **Consider scalability**: Write asynchronous, non-blocking Python endpoints (`async def`) and stateless API handlers.
9. **Protect user data**: Adhere strictly to `/docs/PRIVACY.md` encryption standards (TLS 1.3, AES-256 at-rest).
10. **Build like a production engineering team**: Enforce rigorous pre-commit linting, type verification, and comprehensive automated review.
